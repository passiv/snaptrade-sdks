# SnapTrade MCP Connector Support

Use this page for help with SnapTrade's hosted MCP connector in ChatGPT, Codex, Claude, or another compatible AI client. The connector URL is `https://mcp.snaptrade.com/mcp`.

For help with sign-in, connecting a brokerage, missing or stale account data, or a connector error, email **support@snaptrade.com**. Tell us which AI client you use, what you were trying to do, the time of the problem, and any error message. If a brokerage connection is involved, include its name. Do not email passwords, access tokens, one-time connection links, or full brokerage account numbers.

## Common checks

- **The assistant cannot see an account.** Check that the brokerage appears in your [SnapTrade dashboard](https://dashboard.snaptrade.com) and that you authorized the AI client to access SnapTrade. The connector is for SnapTrade Personal accounts.
- **A brokerage needs attention.** Open your SnapTrade dashboard to repair the connection. If you cannot restore it there, contact support. Account values reflect the latest data the brokerage has made available.
- **A connection link expired.** Ask the assistant for a new link and open it in your own browser. Links are single-use and expire after five minutes.
- **An app or Wealth Rank result is unavailable.** These features may be unavailable for an account or lack enough current data. If you think the result is wrong, contact support with the non-sensitive details above.
- **You want to stop the connector's access.** Revoke the AI client's access in the SnapTrade dashboard under **Settings → Connected apps**. This leaves your brokerage connections in place.

The connector can read account data and create a one-time brokerage connection link. It cannot place trades, move money, or change account settings. See the [MCP server guide](https://docs.snaptrade.com/docs/mcp-server) for setup, tools, and security details, and the [Connector Privacy Notice](https://docs.snaptrade.com/docs/connector-privacy) for data-handling details.

For security vulnerability reports, email **security@snaptrade.com**.
